# 🚀 Superhero App

Повнофункціональний фулстек-застосунок на основі **React + Node.js + TypeScript**.

---

## 📦 Стек технологій
- **Frontend:** React, TypeScript, Vite
- **Backend:** Node.js, Express, TypeScript
- **Database:** PostgreSQL
- **Інше:** Docker, ESLint, Prettier
